# Dynamic Island لأندرويد 🏝️

ده تطبيق بيعمل "Dynamic Island" زي اللي في الآيفون، بس على أندرويد 10 وأعلى، ومعمول مخصوص يشتغل كويس على أندرويد 12 وموبايلات شاومي (MIUI / HyperOS).
الجزيرة بتقعد فوق الكاميرا الأمامية بالظبط، وبتكبر وتصغر بحركة "سبرينج" ناعمة عشان تعرضلك حاجات حقيقية من موبايلك. مفيش أي داتا وهمية.

> ⚠️ **خد بالك:** الكود ده **لسه ماتبناش ولا اتجرب** لا على جهاز ولا على إيميوليتور ولا الـ unit tests اتشغلت. أول build حقيقي هيحصل على GitHub Actions أو على جهازك. لو طلع أي خطأ في الكومبايل ابعته وهنصلحه.

| 🔔 **الإشعارات** | أي رسالة جديدة بتظهر لحظة وبعدين تختفي، مع تحكم كامل في الخصوصية |

| 🚚 **Live Activities** | أي إشعار فيه progress (تحميل، توصيل أوردر، خرايط) بيتحول لنشاط حي، وفيه API لأي تطبيق تاني يبعتلك نشاط |
| 🔋 **الشحن والبطارية** | أول ما توصل الشاحن بيقولك النسبة وسرعة الشحن بالوات، وبينبهك لما البطارية توصل 20% و10% و5% |
| 📶 **الاتصال** | واي فاي، داتا، VPN، أوفلاين، وأجهزة البلوتوث |

| 📋 **الحافظة (Clipboard)** | دبل تاب على الجزيرة يوريك المنسوخ، أو اعمل Share لأي نص واختار "Pin to Island" |

## الحركات (Gestures)

- **تاب**: تفتح / تقفل الجزيرة
- **ضغطة طويلة**: تفتح التطبيق صاحب الإشعار أو الأغنية
- **سحب لفوق**: تخفي الحاجة اللي معروضة
- **دبل تاب**: تعرض الحافظة
- **تاب برة الجزيرة**: تقفلها

## التخصيص (24 اختيار)

العرض والطول (وهي صغيرة ووهي كبيرة)، مكانها يمين وشمال وفوق وتحت، دوران الحواف، قوة السبرينج والارتداد، وقت القفل الأوتوماتيك، الشفافية، اللون (أو ألوان Material You من خلفيتك)، تشغيل وقفل كل ميزة لوحدها، مستوى خصوصية الإشعارات، إخفاء المحتوى والموبايل مقفول، حد سرعة النت، والإخفاء في الوضع العرضي.

وفيه **Presets** جاهزة: Classic و Minimal و Bouncy و Glass و Private و Battery saver.
وتقدر **تعمل Export** لإعداداتك في ملف JSON و**Import** تاني على أي موبايل.

## الخصوصية 🔒

- 3 مستويات: تعرض كل حاجة، تخفي نص الرسالة وتسيب اسم الراسل، أو اسم التطبيق بس.
- والموبايل مقفول، المحتوى بيستخبى أوتوماتيك، والإشعارات اللي التطبيق نفسه معلمها "سرية" مش بتظهر خالص.
- الباسوردات والأكواد اللي بتتنسخ (لو التطبيق معلمها sensitive) بتظهر نجوم.
- التطبيق **مالوش صلاحية إنترنت أصلاً**، يعني ولا حاجة بتخرج من موبايلك.

## إزاي تبنيه

### على GitHub (الأسهل)
1. ارفع الفولدر ده على ريبو جديد.
2. الـ workflow اللي في `.github/workflows/build.yml` هيشتغل لوحده: يجهز Java 17 و Android SDK، ويشغل `setup.sh`، ويعمل الـ unit tests، ويبني الـ APK.
3. هتلاقي الـ APK في **Actions ← آخر run ← Artifacts ← DynamicIsland-apk**.
4. لو عملت tag زي `v1.0.0` واتعمله push، هيتعمل **Release** لوحده والـ APK متعلق فيه.
5. (اختياري) عشان توقع الـ release بمفتاحك، حط في الـ Secrets: `SIGNING_KEYSTORE_BASE64` و`SIGNING_STORE_PASSWORD` و`SIGNING_KEY_ALIAS` و`SIGNING_KEY_PASSWORD`. من غيرهم الـ release هيتوقع بمفتاح الـ debug عشان يتسطب عادي.

### على جهازك
محتاج JDK 17 و Android SDK (platform 34):
```bash
./setup.sh                       # بيعمل هيكل مشروع أندرويد كامل + Gradle wrapper
./gradlew testDebugUnitTest      # الـ unit tests
./gradlew assembleDebug          # الـ APK في app/build/outputs/apk/debug/
```
`setup.sh` بياخد ملفات الكوتلن اللي في الروت ويحط كل ملف في الفولدر المظبوط حسب الـ package بتاعه، ويعمل الـ resources وملفات Gradle. ممكن تشغله كذا مرة عادي.

## أول تشغيل

1. افتح التطبيق ودوس **Grant** جنب كل صلاحية:
   - **Display over other apps**: لازم، من غيرها الجزيرة مش هتظهر.
   - **Notification access**: للإشعارات والمكالمات والميديا.
   - **Post notifications**: عشان التايمر يرن.
   - **Unrestricted battery**: عشان السيستم مايقفلهاش.
   - **Nearby devices**: عشان أسماء أجهزة البلوتوث (اختياري).
2. شغل سويتش **Show the island**.

### لو موبايلك شاومي / ريدمي / بوكو 📱
MIUI و HyperOS بيقفلوا التطبيقات اللي شغالة في الخلفية بعنف. التطبيق هيعرف لوحده إن موبايلك شاومي ويوريك صفحة شرح فيها زراير بتوديك على طول لـ:
1. **Autostart** شغله.
2. **Other permissions** وشغل "Display pop-up windows while running in background".
3. **Battery saver** وخليه "No restrictions".
4. اقفل التطبيق في الـ Recents (القفل الصغير).

## هيكل المشروع

## ملاحظات بصراحة

- أندرويد مش بيسمح لأي تطبيق يكتب جوه الـ status bar نفسه، فالجزيرة overlay فوق كل حاجة. في شاشة القفل نفسها (keyguard) أندرويد مش بيعرض overlays.
- قراءة الحافظة في الخلفية ممنوعة من أندرويد 10. عشان كده بنقراها بس لما تعمل دبل تاب (الجزيرة بتاخد الفوكس ثانية وبترجعه)، أو لما تعمل Share لنص.
- صلاحية `QUERY_ALL_PACKAGES` موجودة عشان أيقونات التطبيقات تظهر. لو هترفعه على Google Play هتحتاج تبررها.
