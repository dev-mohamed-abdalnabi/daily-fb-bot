# Dynamic Island — جزيرة ديناميكية على مستوى النظام (Redmi Note 10)

مشروع Android (Kotlin) يرسم جزيرة ديناميكية حول كاميرا الـ punch-hole، ويُبنى تلقائيًا بواسطة GitHub Actions.

> **حالة المشروع بصدق:** كُتبت الملفات ورُوجعت من المصدر فقط. لم يتم تشغيل Gradle ولا بناء APK ولا اختبار على هاتف حقيقي.
> أول Build على GitHub هو أول اختبار فعلي؛ إن فشل، انسخ رسالة الخطأ من تبويب Actions وأرسلها لإصلاحها.

## 1) رفع الملفات من الهاتف
1. أنشئ مستودعًا جديدًا على github.com (من متصفح الهاتف، وضع «سطح المكتب» أسهل).
2. **Add file ← Upload files** وارفع **كل ملفات الجذر** (`*.kt`, `*.kts`, `setup.py`, `AndroidManifest.xml`, `gradle.properties`, `.gitignore`...). لا توجد مجلدات لرفعها.
3. المجلد الوحيد المطلوب: **Add file ← Create new file** واكتب في خانة الاسم بالضبط `.github/workflows/build.yml` (الشرطة المائلة تُنشئ المجلدات)، ثم الصق محتوى `build.yml` واضغط Commit.
4. بعد الـ Commit يبدأ البناء تلقائيًا (وعند كل Push لاحق). يمكن أيضًا تشغيله يدويًا: **Actions ← Build APK ← Run workflow**.

## 2) استخراج الـ APK
- **Actions ← آخر تشغيل ناجح ← Artifacts ← DynamicIsland-APK** (ملف zip بداخله `DynamicIsland.apk`).
- لإنشاء Release تلقائي: أنشئ Tag يبدأ بـ `v` مثل `v1.0.0` فيُرفق الـ APK بالـ Release.
- الـ APK موقّع بمفتاح debug (قابل للتثبيت مباشرة). للنشر الرسمي استبدله بمفتاحك الخاص.

## 3) أول تشغيل على الهاتف
1. افتح التطبيق وفعّل **خدمة إمكانية الوصول** (الخطوة 1، هي التي تجعل الجزيرة تُرسم **فوق** شريط الحالة)، ثم امنح **الوصول إلى الإشعارات** و**الظهور فوق التطبيقات**.
2. اتبع **تعليمات Xiaomi** داخل التطبيق (Autostart، البطارية بدون قيود، قفل التطبيق في Recent).
3. من **التخصيص** اضبط الإزاحة الأفقية/الرأسية إن لم تتطابق الجزيرة تمامًا مع الكاميرا، واستخدم «معاينة».

## الصلاحيات
| الصلاحية | السبب |
|---|---|
| SYSTEM_ALERT_WINDOW | رسم الجزيرة فوق التطبيقات |
| Notification Listener (وصول للإشعارات) | معاينة الإشعارات/المكالمات/التنزيلات/الملاحة، وقراءة جلسات الوسائط |
| FOREGROUND_SERVICE | إبقاء الجزيرة تعمل |
| POST_NOTIFICATIONS | إشعار الخدمة الصغير (Android 13+) |
| RECEIVE_BOOT_COMPLETED | استعادة الجزيرة بعد الإقلاع |
| ACCESS_NETWORK_STATE | حالة Wi-Fi/البيانات/VPN |
| BLUETOOTH_CONNECT (و BLUETOOTH ≤ Android 11) | اسم جهاز Bluetooth عند الاتصال (اختياري) |
| VIBRATE | اهتزاز خفيف وتنبيه انتهاء المؤقت |
| خدمة إمكانية الوصول | رسم الجزيرة **فوق** شريط الحالة فقط؛ لا تقرأ أي محتوى |

لا يوجد INTERNET. لا شيء يُرسل خارج الجهاز.

## الوظائف المنفّذة (مرتبطة بمصادر حقيقية)
- **سرعة الشبكة:** تنزيل/رفع بـ KB/s وMB/s من `TrafficStats`، نوع الاتصال، إجمالي الجلسة عند الضغط. تظهر أثناء النقل فقط.
- **الوسائط:** `MediaSession` — تشغيل/إيقاف/التالي/السابق، الاسم، الفنان، الغلاف، شريط التقدم والمدة.
- **الإشعارات:** اسم التطبيق وأيقونته، تجميع إشعارات نفس التطبيق (×N)، أزرار الإجراءات، فلترة التطبيقات (سماح/حظر)، إخفاء النص اختياريًا وعلى شاشة القفل.
- **المكالمات والتنزيلات والملاحة وتحديثات التطبيقات:** من إشعارات هذه الفئات (تقدم حقيقي).
- **الشحن:** نسبة، نوع الشاحن، الوقت المتبقي عندما يوفره النظام، اكتمال الشحن، انخفاض البطارية.
- **الاتصال:** Wi-Fi، بيانات الجوال، VPN، Bluetooth (وأسماء الأجهزة)، وضع الطيران.
- **المؤقت:** ساعة إيقاف ومؤقت تنازلي يستمران بعد قتل العملية.
- **الميكروفون:** تنبيه عند التسجيل الصوتي.
- **التخصيص:** الحجم، الانحناء، الألوان، الشفافية، سرعة ونوع الحركة، المدة، الموضع، تفعيل الميزات، ترتيب الأولويات، قوالب جاهزة، وضع ليلي، اهتزاز، استيراد/تصدير.
- **الاستمرارية:** خدمة أمامية، BootReceiver، WorkManager Watchdog، حفظ الحالة، منع تكرار الخدمات، إيقاف الأنيميشن عند الإخفاء.

## قيود معروفة (حدود Android الحقيقية)
- **الحافظة:** من Android 10 لا يُسمح لتطبيق في الخلفية بقراءة الحافظة، لذا **لم تُنفَّذ** معاينة الحافظة (لا بديل رسمي دون Accessibility أو لوحة مفاتيح مخصصة).
- **فوق شريط الحالة:** هذا هو الوضع الافتراضي ويتطلب تفعيل خدمة إمكانية الوصول. بدونها يرجع التطبيق إلى نافذة Overlay عادية تقع تحت شريط الحالة فتظهر الساعة والأيقونات فوق الجزيرة الموسعة.
- **الميكروفون:** قد يُخفي النظام بعض تسجيلات التطبيقات الأخرى حسب الإصدار.
- **المكالمات:** تعتمد على إشعار المكالمة؛ أزرار الرد/الرفض تظهر إذا وفّرها تطبيق الاتصال في إشعاره.
- **الاتجاه الأفقي:** تُخفى الجزيرة في الوضع الأفقي.
- **MIUI:** لا يمكن منع النظام من قتل التطبيق 100%؛ التطبيق يعيد نفسه، لكن الاستمرارية تتطلب إعدادات Xiaomi المشروحة داخل التطبيق.
- واجهة التطبيق بالعربية فقط حاليًا.
